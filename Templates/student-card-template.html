📌 Student Card Template

Copy the <div class="card">...</div> block below and paste it inside the .cards container on the Students.html page. Then change the red [ ... ] placeholders. 

<div class="card">
  <a href="Student-Pages/[first-last].html">
    <img
      class="card-photo"
      src="Pictures/[photo-file]"
      alt="[Full Name] photo"
    />
    <div class="card-body">
      <h3>[Full Name]</h3>
      <p class="card-role">[Grade / Class Year]</p>
    </div>
  </a>
</div>

Steps to add a NEW student

  1. Add their photo file to the Pictures/ folder (e.g. Pictures/jane-doe.jpg).
  2. Copy the card snippet above into Students.html and fill in the placeholders.
  3. Create their own page in Student-Pages/ using the other template (student-page-template.html).
  4. Make sure the href in the card matches the file name of the page you created in Student-Pages/.
